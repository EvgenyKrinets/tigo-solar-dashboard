# Tigo Solar Dashboard v2.23.2

## v2.23.2
Statistics tiles are now interactive. Click Minimum, Maximum or Average for Power, Temperature, Energy, RSSI and other enabled statistics to open an aggregated 24-hour chart for the currently selected panels.

Desktop roof image now fills its container at natural aspect ratio, without empty space to the right. Zoom controls and wheel zoom are mobile-only. On mobile, pinch zoom and panning remain available, and the roof viewport stays bounded.

Install: replace `/config/custom_components/tigo_solar_dashboard`, restart Home Assistant, hard-refresh browser or restart mobile app.
